# karatsuba_gen — генератор конвейерного умножителя Карацубы на Verilog

## Назначение

`karatsuba_gen` — консольная программа на C++17 для Linux. Она принимает
натуральное число `N` (разрядность) и записывает Verilog-описание (`*.v`)
схемы, которая умножает два неотрицательных целых `N`-битных числа по
**алгоритму Карацубы**:

* результат (`2N` бит) выдаётся на **3-й такт** после подачи операндов;
* новые операнды можно подавать на каждом такте, результаты тоже выходят на
  каждом такте (**конвейер**);
* оператор умножения `*` в схеме не используется: всё умножение сведено к
  побитовому «И», сложению, вычитанию и сдвигам;
* код — синтезируемый Verilog-2001.

Интерфейс сгенерированного модуля `karatsuba_mul`:

| Порт | Ширина | Назначение |
|---|---|---|
| `clk` | 1 | тактовый сигнал, всё работает по переднему фронту |
| `a`, `b` | `N` | множители |
| `p` | `2N` | произведение `a · b` для операндов, поданных 3 такта назад |

Необходимо установить

Ubuntu/Debian:

```sh
sudo apt-get install g++ cmake
```


### Сборка

Всё собирается CMake:

```sh
git clone https://github.com/bladexyzx/karatsuba_gen.git 
cd karatsuba_gen
cmake -B build
cmake --build build
```


### Тесты

```sh
ctest --test-dir build --output-on-failure
```

20 тестов на Doctest проверяют функции генератора и разбора аргументов: для
функций, которые проверяют входные данные, — правильные и неправильные
входные данные. Модель арифметики
схемы на C++ (шаги Карацубы и листы из «И» и сумматоров) сверяется с обычным
умножением для всех `N` ≤ 32. Отдельный тест сверяет текст листа 4 × 4:
он собран из «И» и сумматоров. Тест конвейера проверяет в сгенерированном
тексте, что от входов `a`, `b` до выхода `p` ровно три ступени регистров и
каждая ступень берёт данные только из предыдущей, то есть результат выходит
на 3-м такте, а новые операнды принимаются на каждом такте.

## Использование

```
build/karatsuba_gen N [опции]
```

| Опция | Назначение |
|---|---|
| `N` | разрядность операндов, 1…4096 |
| `-o, --output FILE` | выходной файл (по умолчанию `karatsuba_mul.v` в текущем каталоге) |
| `-h, --help` | справка |

Путь в `-o` может быть любым, относительным или абсолютным.
Коды возврата: `0` — успешно, `1` — не удалось записать файл, `2` — неверные
аргументы.





## Тестбенч: перемножить свои числа

Нужен Icarus Verilog (`sudo apt-get install iverilog`).

```console
$ build/karatsuba_gen 32
$ iverilog -g2005 -P tb.N=32 -o tb.vvp karatsuba_mul.v tests/tb.v
$ vvp -n tb.vvp +a=123456789 +b=987654321
123456789 * 987654321 = 121932631112635269
OK
```

`tb.N` должен совпадать с `N` генератора. Числа задаются десятичными `+a=...`
и `+b=...` (без них берутся 12345 и 6789). Тестбенч подаёт числа, ждёт 3 такта
и печатает `p`; `OK` означает, что результат совпал с `a * b`.
