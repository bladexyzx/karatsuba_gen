Detailed Description

Emits the synthesisable RTL (TOP is the top level name):

  • TOP_leaf_wK: K x K combinational leaf multiplier (K <= base);
  • TOP_kara_wK: K x K combinational Karatsuba step (K > base);
  • TOP: pipelined top level, its own Karatsuba step is spread over three register stages (latency 3, one result per clock).
