Detailed Description

Emits the synthesisable RTL:

  • karatsuba_mul_leaf_wK: K x K combinational leaf, long multiplication from bitwise AND and adders (K <= kLeafWidth);
  • karatsuba_mul_kara_wK: K x K combinational Karatsuba step;
  • karatsuba_mul: pipelined top level, its own Karatsuba step is spread over three register stages (latency 3, one result per clock). The Verilog multiplication operator '*' is never emitted, the output contains no '*' character at all (not even in comments): every product is reduced to AND, addition, subtraction and shifts.
